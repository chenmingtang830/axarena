# AXArena methodology

AXArena measures whether a host agent can complete real sandbox work through a product's API or CLI surface. Only deterministic live-state read-back oracles decide pass or fail.

Codex and Claude Code have independent leaderboards. Overall, API, and CLI are stored views. Discovery, readiness, transcript, journey, latency, tokens, and cost do not affect usability rank.

The presentation sprint uses synthetic values and must not be cited.
